# Stage 03：IR 笔记

> 实验任务书与指导书现已发布。本笔记以它们定义的输入、输出和必做范围为准，
> 并保留本地 `irsim` 的运行验证，用来确认文本 IR 的执行语义。

## 1. IR 在本实验中的位置

```text
C-- 源程序
  -> Stage 01：AST
  -> Stage 02：语义分析
  -> Stage 03：生成文本形式的三地址码 IR
  -> irsim：读取并执行 .ir，验证行为
```

IR 不是全世界唯一统一的一门语言。本实验使用的是一套文本形式、可由 `irsim`
执行的三地址码风格 IR。

## 2. 任务接口与必做范围

评测调用形式是：

```bash
./cc input.cmm output.ir
```

因此 Stage 03 不再把 IR 打到标准输出，而是创建并写入第二个参数指定的文件。本仓库的
`make` 会同时保留旧阶段的 `./parser`，并生成与手册一致的 `./cc`：

```bash
make
./cc input.cmm output.ir
```

任务书的必做部分包含整数表达式、局部变量、函数调用、`if`/`while`、`read`/`write`
和一维数组；结构体、多维数组和数组形参属于选做范围。输入假定已经通过词法、语法和
语义分析，且没有全局变量、同名变量或缺失的 `return`。

## 3. IR 语法

| 目的 | 已验证写法 | 说明 |
| --- | --- | --- |
| 程序入口 | `FUNCTION main :` | `main` 是模拟器入口。 |
| 常量 | `#42` | `#` 前缀表示立即数。 |
| 赋值 | `t1 := #20` | `t1` 是临时变量。 |
| 算术 | `t3 := t1 + t2` | `+` 已验证；模拟器还静态支持 `-`、`*`、`/`。 |
| 输出 | `WRITE t3`、`WRITE #42` | 输出到 IR Simulator 的 Console。 |
| 返回 | `RETURN #0` | `main` 正常结束。 |
| 条件跳转 | `IF t1 > t2 GOTO label1` | 已验证 `>` 与真分支跳转。 |
| 无条件跳转 | `GOTO label2` | 用于跳过另一分支或回到循环头。 |
| 标签 | `LABEL label1 :` | 是跳转目标。 |
| 输入 | `READ t1` | 模拟器弹出整数输入框。 |
| 函数参数 | `PARAM x` | 形参从调用方的参数栈取得值。 |
| 函数调用 | `ARG t1` / `t2 := CALL inc` | 已验证单参数调用和返回值。 |

## 4. 调用约定：实参倒序生成

`irsim` 的 `ARG` 使用栈：**离 `CALL` 最近的实参先绑定第一个 `PARAM`**。

因此，若 C-- 调用是：

```c
sub(10, 3)
```

应生成：

```ir
ARG #3
ARG #10
t1 := CALL sub
```

这样被调函数中的 `PARAM a` 得到 `10`，`PARAM b` 得到 `3`。反过来生成
`ARG #10` 后再生成 `ARG #3`，则 `a - b` 的结果是 `-7`。

## 5. 内存语法

下列形式已经由 `memory.ir` 实际执行确认：

```ir
DEC v1 8
t1 := &v1
*t1 := #10
t2 := t1 + #4
t3 := *t2
```

- `DEC name size`：分配 `size` 字节；模拟器要求 `size` 是 4 的倍数。
- `&name`：取变量或聚合对象的基地址。
- `*address := value`：向地址写入一个整数值。
- `target := *address`：从地址读取一个整数值。

`memory.ir` 为两个 4 字节位置分配了 8 字节，将 `10`、`32` 分别写入两个位置后
再读回并相加。模拟器的 Watch 视图显示 `v1 = [10, 32]`，Console 输出 `42`。
这些规则是数组元素和结构体字段访问的基础。

## 6. 当前实现与后续边界

- 当前生成器已覆盖必做范围中的整数、局部变量、函数、分支/循环、`read/write` 和
  一维数组，并以 `vN` 映射源变量、以 `tN` 保存临时值，避免命名冲突。
- 结构体、多维数组、数组形参和浮点数目前会使 IR 生成失败；它们应在选做任务开始时
  再按指导书的地址计算规则扩展。
- `irsim.pyc` 和虚拟环境只用于本地验证，受 `.gitignore` 保护，不是提交产物。
