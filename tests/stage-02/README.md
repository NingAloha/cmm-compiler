# Stage 02 测试用例

当前实验二已完成类型系统和全局符号表，语义分析尚未接入 `parser`。两个测试都是独立的 C 单元测试：它们直接链接语义模块，不依赖 Flex、Bison 或实验一的语法树输出。

在项目根目录运行：

```bash
make test-02
```

预期输出：

```text
type tests passed
symbol table tests passed
```

当前覆盖点：

- `int` 与 `float` 的共享类型对象和类型等价；
- `int`、`float` 的数值类型判断；
- 一维、二维数组的类型等价；
- 数组长度不参与类型等价、数组维数参与类型等价；
- 不同结构体定义在名等价规则下不相等。
- 符号表的初始化、插入、按名查找和清空；
- 重复符号拒绝，且原有符号不会被覆盖；
- 变量、函数和结构体符号的类别与类型记录。

运行 `make test` 会依次运行 `make test-01` 和 `make test-02`。
